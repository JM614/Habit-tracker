# Habit Tracker 🌱

Una app sencilla para llevar el seguimiento de tus hábitos diarios, hecha en un solo archivo HTML (sin necesidad de instalar nada).

## Características

- ✅ Añade y elimina hábitos
- 🔥 Rachas (días seguidos cumpliendo un hábito)
- 📊 Estadísticas rápidas: porcentaje del día, número de hábitos, mejor racha
- 🗓️ Mapa de calor de los últimos 12 semanas por hábito
- 🌙 Modo claro / oscuro
- 💾 Guarda todo en el navegador (`localStorage`), no requiere servidor ni base de datos

## Cómo usarlo

1. Descarga o clona este repositorio
2. Abre el archivo [`index.html`](index.html) directamente en tu navegador
3. ¡Empieza a añadir tus hábitos!

## Tecnologías

HTML, CSS y JavaScript puro (sin frameworks ni dependencias externas).
